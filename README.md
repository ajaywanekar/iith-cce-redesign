# IITH CCE: Event Page Redesign + Chatbot

A student prototype that improves the IIT Hyderabad CCE event page for
**"Driving Organisational Effectiveness Through Employee Experience"**.

> Not the official page. Official page: https://cce.iith.ac.in/driving-organisational-effectiveness.html

## Pages
| Page | Description |
|---|---|
| [`index.html`](index.html) | Full redesign plus the chatbot |
| [`original-with-chatbot.html`](original-with-chatbot.html) | The original page with only the chatbot added |
| [`chatbot-snippet.html`](chatbot-snippet.html) | Standalone chatbot. Paste it before `</body>` on any page |

## Chatbot
- Floating assistant in the bottom-right corner, styled to match the page
- Answers questions about fees, dates, schedule, venue, faculty, registration, certificate, FAQs, and general IIT Hyderabad info (history, departments, how to reach, CCE)
- Includes quick-reply buttons and a typing indicator, and works on mobile
- Runs fully in the browser with no server or API key: a keyword-weighted knowledge base

## Redesign highlights
Sticky navigation · hero image with key facts · live registration countdown · stats strip ·
